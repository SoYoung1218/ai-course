전화번호를 어떤 형식으로 정리하고 싶으신가요? 상황에 따라 가장 많이 쓰이는 **3가지 방식(하이픈 추가, 숫자만 추출, 특정 포맷 통일)**의 파이썬 함수를 만들어 보았습니다.

### 1. 숫자만 남기고 하이픈(`-`)을 넣어 예쁘게 만들기
사용자가 `01012345678`, `010-1234-5678`, `010 1234 5678` 중 무엇을 입력해도 동일하게 `010-1234-5678`로 만들어줍니다.

```python
import re

def format_phone_number(phone):
    # 1. 숫자 이외의 모든 문자 제거
    digits = re.sub(r'\D', '', phone)
    
    # 2. 길이에 따라 하이픈 삽입
    length = len(digits)
    
    if length == 11: # 010-1234-5678 형식
        return f"{digits[:3]}-{digits[3:7]}-{digits[7:]}"
    elif length == 10: # 02-123-4567 또는 010-123-4567 형식
        if digits.startswith('02'): # 서울 지역번호 특수 처리
            return f"{digits[:2]}-{digits[2:5]}-{digits[5:]}"
        else:
            return f"{digits[:3]}-{digits[3:6]}-{digits[6:]}"
    elif length == 9: # 02-12-3456 형식
        return f"{digits[:2]}-{digits[2:4]}-{digits[4:]}"
    else:
        return digits  # 형식이 맞지 않으면 그대로 반환

# 테스트
test_numbers = ["01012345678", "010-1234-5678", "021234567", "010 1234 5678", "010.1234.5678"]
for num in test_numbers:
    print(f"{num} -> {format_phone_number(num)}")
```

### 2. 데이터 분석용: 숫자만 깔끔하게 추출하기
DB에 저장하거나 계산을 위해 기호(하이픈, 공백 등)를 모두 없애고 싶을 때 사용합니다.

```python
import re

def clean_phone_number(phone):
    # 숫자가 아닌 모든 문자를 빈 문자열로 대체
    return re.sub(r'\D', '', phone)

# 테스트
print(clean_phone_number("010-1234-5678")) # 결과: '01012345678'
print(clean_phone_number("(02) 123-4567")) # 결과: '021234567'
```

### 3. 리스트 전체를 한 번에 정리하기 (Pandas 활용)
엑셀 파일이나 CSV 데이터를 다루고 있다면 `pandas` 라이브러리를 사용하는 것이 가장 빠릅니다.

```python
import pandas as pd
import re

def clean_phone_column(df, column_name):
    # 해당 컬럼의 모든 값을 문자열로 바꾸고 숫자만 남긴 뒤, 하이픈 적용
    def apply_format(x):
        digits = re.sub(r'\D', '', str(x))
        if len(digits) == 11:
            return f"{digits[:3]}-{digits[3:7]}-{digits[7:]}"
        elif len(digits) == 10:
            return f"{digits[:3]}-{digits[3:6]}-{digits[6:]}"
        return digits

    df[column_name] = df[column_name].apply(apply_format)
    return df

# 예시 데이터 생성
data = {'name': ['김철수', '이영희', '박민수'],
        'phone': ['010-1234-5678', '01012345678', '02 123 4567']}
df = pd.DataFrame(data)

# 실행
df = clean_phone_column(df, 'phone')
print(df)
```

### 어떤 함수가 필요하신가요?
1. **"입력값이 제각각이라서 통일하고 싶다"** $\rightarrow$ **1번** 추천
2. **"기호를 다 지우고 숫자만 갖고 싶다"** $\rightarrow$ **2번** 추천
3. **"엑셀 파일을 불러와서 한꺼번에 바꾸고 싶다"** $\rightarrow$ **3번** 추천
