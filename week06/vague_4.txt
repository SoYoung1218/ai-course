전화번호를 어떤 형식으로 정리하고 싶은지에 따라 여러 가지 방법이 있습니다. 가장 대표적인 세 가지 상황(하이픈 추가, 숫자만 추출, 특정 포맷으로 통일)에 맞춰 파이썬(Python) 코드를 작성해 드립니다.

### 1. 숫자만 남기고 하이픈(`-`)을 넣어 정규화하기
가장 많이 쓰이는 방식입니다. 입력값이 `01012345678`, `010-1234-5678`, `010 1234 5678` 등 제각각일 때 이를 하나로 통일합니다.

```python
import re

def format_phone_number(phone_str):
    # 1. 숫자 이외의 모든 문자 제거
    digits = re.sub(r'\D', '', phone_str)
    
    # 2. 길이에 따른 포맷팅
    length = len(digits)
    
    if length == 11:  # 010-1234-5678 형태
        return f"{digits[:3]}-{digits[3:7]}-{digits[7:]}"
    elif length == 10: # 02-123-4567 또는 010-123-4567 형태
        # 앞자리가 3자리인 경우 (서울 지역번호 등)
        if digits.startswith('02'):
            return f"{digits[:2]}-{digits[2:5]}-{digits[5:]}"
        else:
            return f"{digits[:3]}-{digits[3:6]}-{digits[6:]}"
    elif length == 9:  # 02-12-3456 형태
        return f"{digits[:2]}-{digits[2:4]}-{digits[4:]}"
    else:
        # 형식이 맞지 않으면 원래 숫자만 반환하거나 에러 처리
        return digits

# 테스트
test_numbers = ["01012345678", "010-1234-5678", "021234567", "010 1234 5678", "02-123-4567"]
for num in test_numbers:
    print(f"{num}  =>  {format_phone_number(num)}")
```

### 2. 데이터 분석용 (숫자만 추출하기)
DB에 저장하거나 계산을 위해 하이픈을 모두 제거하고 숫자만 남기고 싶을 때 사용합니다.

```python
import re

def clean_phone_number(phone_str):
    # 숫자만 추출하여 문자열로 반환
    return re.sub(r'\D', '', phone_str)

# 테스트
print(clean_phone_number("010-1234-5678")) # 출력: '01012345678'
```

---

### 3. 리스트 형태의 전화번호 일괄 정리하기
여러 개의 전화번호가 들어있는 리스트를 한 번에 정리할 때 유용합니다.

```python
def format_phone_list(phone_list):
    return [format_phone_number(num) for num in phone_list]

# 테스트
raw_data = ["01012345678", "02-123-4567", "010 9876 5432"]
cleaned_data = format_phone_list(raw_data)
print(cleaned_data) 
# 출력: ['010-1234-5678', '02-123-4567', '010-9876-5432']
```

---

### 💡 코드 설명 및 팁

1.  **`re.sub(r'\D', '', phone_str)`**: 정규표현식을 사용하여 숫자가 아닌 것(`\D`)을 모두 빈 문자열(`''`)로 바꿉니다. 즉, 하이픈, 공백, 괄호 등을 한 번에 지워줍니다.
2.  **조건문 분기**: 한국 전화번호 체계는 지역번호(02)와 휴대폰 번호(010)에 따라 자릿수가 달라질 수 있습니다. 위 코드는 이를 고려하여 `len()`을 기준으로 슬라이싱(`[:]`)을 합니다.
3.  **확장성**: 만약 해외 전화번호까지 처리해야 한다면 훨씬 복잡한 규칙이 필요하지만, 국내용으로는 위 코드로 충분합니다.
