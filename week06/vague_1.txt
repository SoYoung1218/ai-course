전화번호를 어떤 형식으로 정리하고 싶은지에 따라 여러 가지 방법이 있습니다. 가장 대표적인 세 가지 상황(하이픈 추가, 숫자만 추출, 특정 포맷으로 통일)에 맞춘 파이썬 함수들을 만들어 보았습니다.

### 1. 모든 숫자를 하이픈(`-`)이 있는 표준 형식으로 만들기
입력된 값이 `01012345678`처럼 숫자만 있거나, 형식이 제각각일 때 `010-1234-5678` 형태로 변환합니다.

```python
import re

def format_phone_number(phone):
    # 1. 숫자만 남기고 모두 제거
    digits = re.sub(r'\D', '', str(phone))
    
    # 2. 길이에 따라 하이픈 삽입
    length = len(digits)
    
    if length == 11:  # 010-1234-5678 형식
        return f"{digits[:3]}-{digits[3:7]}-{digits[7:]}"
    elif length == 10: # 02-123-4567 또는 010-123-4567 형식
        if digits.startswith('02'): # 서울 지역번호 예외 처리
            return f"{digits[:2]}-{digits[2:5]}-{digits[5:]}"
        else:
            return f"{digits[:3]}-{digits[3:6]}-{digits[6:]}"
    elif length == 9:  # 02-12-3456 형식
        return f"{digits[:2]}-{digits[2:4]}-{digits[4:]}"
    else:
        return digits  # 형식이 맞지 않으면 그대로 반환

# 테스트
print(format_phone_number("01012345678"))      # 010-1234-5678
print(format_phone_number("021234567"))      # 02-123-4567
print(format_phone_number("010-1234-5678"))  # 010-1234-5678 (이미 되어있어도 OK)
print(format_phone_number("010.1234.5678"))   # 010-1234-5678
```

### 2. 불필요한 기호 제거하고 "숫자만" 남기기
데이터베이스에 저장하거나 계산할 때 유용합니다.

```python
import re

def clean_phone_number(phone):
    # 숫자가 아닌 모든 문자를 빈 문자열로 대체
    return re.sub(r'\D', '', str(phone))

# 테스트
print(clean_phone_number("010-1234-5678"))  # 01012345678
print(clean_phone_number("(02) 123-4567")) # 021234567
```

### 3. 리스트 형태의 전화번호 일괄 정리하기 (Pandas 활용)
엑셀이나 CSV 파일을 다루고 있다면 `pandas` 라이브러리를 사용하는 것이 가장 효율적입니다.

```python
import pandas as pd
import re

def clean_phone_series(series):
    # 숫지만 추출하는 함수 정의
    def extract_digits(x):
        return re.sub(r'\D', '', str(x))
    
    # 숫자만 추출한 뒤 하이픈 적용 (간단 버전)
    def apply_format(digits):
        if len(digits) == 11:
            return f"{digits[:3]}-{digits[3:7]}-{digits[7:]}"
        elif len(digits) == 10:
            return f"{digits[:3]}-{digits[3:6]}-{digits[6:]}"
        return digits

    return series.apply(extract_digits).apply(apply_format)

# 테스트 데이터 생성
data = {'name': ['Kim', 'Lee', 'Park', 'Choi'],
        'phone': ['010-1234-5678', '010.9876.5432', '(02)1234567', '01011112222']}
df = pd.DataFrame(data)

# 함수 적용
df['phone_cleaned'] = clean_phone_series(df['phone'])

print(df)
```

### 요약: 어떤 것을 쓸까요?
1. **사용자 입력값을 바로 보여줘야 한다면?** $\rightarrow$ **1번** 함수
2. **DB에 저장하기 위해 깔끔하게 만들고 싶다면?** $\rightarrow$ **2번** 함수
3. **엑셀 파일(CSV)에 있는 수천 개의 번호를 고쳐야 한다면?** $\rightarrow$ **3번** 방식
