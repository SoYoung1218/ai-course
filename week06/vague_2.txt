전화번호를 어떤 형식으로 정리하고 싶으신가요? 보통 가장 많이 쓰이는 두 가지 방식(**하이픈(-) 제거** 또는 **하이픈(-) 추가**)을 기준으로 파이썬(Python) 함수를 만들어 보았습니다.

### 1. 하이픈(-)을 모두 제거하여 숫자만 남기는 함수
데이터베이스에 저장하거나 숫자만 추출해야 할 때 유용합니다.

```python
import re

def clean_phone_number(phone):
    # 숫자가 아닌 모든 문자를 제거합니다.
    return re.sub(r'\D', '', str(phone))

# 테스트
test_numbers = ["010-1234-5678", "02.123.4567", "010 9876 5432", "01011112222"]
cleaned = [clean_phone_number(n) for n in test_numbers]

print(f"원본: {test_numbers}")
print(f"정리: {cleaned}")
# 출력: ['01012345678', '021234567', '01098765432', '01011112222']
```

### 2. 일정한 형식(010-XXXX-XXXX)으로 통일하는 함수
사용자에게 보여줄 때 깔끔하게 정렬하기 위해 사용합니다. 한국 전화번호의 일반적인 패턴(휴대폰, 지역번호)을 고려했습니다.

```python
import re

def format_phone_number(phone):
    # 1. 먼저 숫자만 남깁니다.
    digits = re.sub(r'\D', '', str(phone))
    
    length = len(digits)
    
    # 2. 길이에 따라 하이픈을 삽입합니다.
    if length == 11:  # 010-1234-5678 형식
        return f"{digits[:3]}-{digits[3:7]}-{digits[7:]}"
    elif length == 10:
        # 02-123-4567 또는 010-123-4567 형식 대응
        if digits.startswith('02'): # 서울 지역번호
            return f"{digits[:2]}-{digits[2:5]}-{digits[5:]}"
        else:
            return f"{digits[:3]}-{digits[3:6]}-{digits[6:]}"
    elif length == 9:  # 02-1234-5678 (짧은 지역번호 등)
        return f"{digits[:2]}-{digits[2:6]}-{digits[6:]}"
    else:
        # 형식이 맞지 않으면 숫자만 반환하거나 예외 처리
        return digits

# 테스트
test_numbers = ["01012345678", "021234567", "010-9876-5432", "0311234567"]
formatted = [format_phone_number(n) for n in test_numbers]

print(f"원본: {test_numbers}")
print(f"정리: {formatted}")
# 출력: ['010-1234-5678', '02-123-4567', '010-9876-5432', '031-123-4567']
```

---

### 💡 코드 설명 및 활용 팁

1.  **`re.sub(r'\D', '', str(phone))`**:
    *   `re`는 정규표현식 모듈입니다.
    *   `\D`는 "숫자가 아닌 모든 문자"를 의미합니다.
    *   따라서 입력값이 `010-1234-5678`이든 `010.1234.5678`이든 상관없이 숫자만 쏙 뽑아냅니다.
2.  **예외 처리**:
    *   위 함수들은 아주 기본적인 로직입니다. 만약 해외 번호나 특수한 형태의 번호를 다뤄야 한다면 `if-elif` 문을 더 확장해야 합니다.
3.  **추천 워크플로우**:
