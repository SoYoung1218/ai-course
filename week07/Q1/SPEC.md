# 단위 변환기 (Unit Converter) 명세서

## 1. 개요
이 애플리케이션은 Flet을 사용하여 구축된 단위 변환기로, 사용자가 입력한 수치를 다양한 길이 단위와 온도 단위로 변환할 수 있게 해줍니다.

## 2. 기능 요구사항

### 2.1 지원 단위
애플리케이션은 다음 두 가지 카테고리의 총 6개 단위를 지원해야 합니다.
- **길이 단위**: `mm`, `cm`, `m`, `km`
- **온도 단위**: `°C`, `°F`

### 2.2 변환 로직
- **길이 변환**: 길이 단위 간의 상호 변환을 지원합니다 (예: `mm` $\leftrightarrow$ `m`).
- **온도 변환**: 온도 단위 간의 상호 변환을 지원합니다 (`°C` $\leftrightarrow$ `°F`).
- **범주 혼합 오류 처리**: 사용자가 '길이' 카테고리와 '온도' 카테고리의 단위를 혼합하여 선택한 경우(예: `cm`를 `°C`로 변환 시도), 변환을 수행하지 않고 안내 문구를 표시합니다.

### 2.3 입력 유효성 검사
- **숫자 확인**: 입력된 값은 반드시 유효한 숫자여야 합니다.
- **비숫자 입력 처리**: 숫자가 아닌 값(예: "abc")이 입력되면 애플리케이션은 다음과 같이 동작해야 합니다.
    1. 결과(Result) 칸을 비웁니다.
    2. 안내 문구(Notice) 영역에 에러 메시지를 표시합니다 (예: "유효한 숫자를 입력해주세요.").

### 2.4 기록 관리
- 성공적인 변환 결과는 리스트 뷰(ListView)에 추가되어 원본 값, 단위, 그리고 변환된 결과를 보여줍니다.
- 각 기록에는 리스트에서 해당 항목을 제거할 수 있는 '삭제' 버튼이 포함되어야 합니다.

## 3. UI 구성 요소 (기존 main.py 구조 기반)

- **입력 필드 (TextField)**: 변환할 수치를 입력받는 칸.
- **단위 드롭다운 (Dropdown)**: 지원되는 6가지 단위 중 하나를 선택하는 메뉴.
- **실행 버튼 (Button)**: 변환 로직을 실행하는 버튼.
- **결과 텍스트 (Text)**: 변환된 값을 보여주는 영역.
- **안내 텍스트 (Text)**: 에러 메시지를 표시하는 영역 (빨간색 글자).
- **기록 리스트 (ListView)**: 이전 변환 결과들을 나열하는 영역.

## 4. 기술 스택
- **언어**: Python
- **프레임워크**: Flet
