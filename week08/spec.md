# 주차 요금 계산기 스펙 문서 (Specification)

## 1. 개요
사용자가 차량의 입차 시각과 출차 시각을 입력하면 주차 요금을 계산하고, 계산 기록을 목록으로 관리하며 오늘 총 합계를 보여주는 프로그램입니다.

## 2. 상세 동작 규칙

### 2.1 시간 입력 및 유효성 검사
- **형식**: `HH:mm` (24시간제, 예: `09:30`, `23:59`)
- **유효성 검사 (Error Handling)**:
    - **잘못된 형식**: `HH:mm` 형식이 아니거나 숫자가 아닌 경우 -> `"올바른 시간 형식(HH:mm)을 입력하세요."` 에러 발생.
    - **범위 초과**: 시(0-23) 또는 분(0-59)이 범위를 벗어난 경우 -> `"시간 범위를 확인하세요 (00:00 ~ 23:59)."` 에러 발생.
    - **논리적 오류 (자정 통과)**: 출차 시각이 입차 시각보다 빠를 경우 (예: 입차 22:00, 출차 02:00) -> `"자정을 넘기는 주차는 지원하지 않습니다."` 에러 발생.
    - **빈 입력**: 값이 비어있는 경우 -> `"입력 값을 모두 채워주세요."` 에러 발생.

### 2.2 요금 산정 규칙
- **기본 무료 시간**: 주차 시작 후 **30분까지 0원**.
- **추가 요금**: 30분 초과 시, **10분당 500원** 부과.
- **올림 처리**: 10분 미만의 잔여 시간도 10분으로 간주하여 계산 (예: 31분 주차 시 10분 단위 1회 적용되어 500원).
- **일일 최대 요금**: 한 번의 주차 시 발생하는 최대 금액은 **20,000원**을 초과할 수 없음.

### 2.3 데이터 관리 및 표시
- **목록 누적**: 계산이 성공할 때마다 `[입차, 출차, 주차시간, 요금]` 정보가 목록에 추가됨.
- **삭제 기능**: 목록의 각 항목 옆에 있는 '삭제' 버튼을 누르면 해당 항목이 제거되고, **오늘의 총 합계**가 즉시 재계산됨.
- **금액 포맷팅**: 모든 금액(개별 요금, 총 합계)은 천 단위마다 콤마(`,`)를 포함하여 표시함 (예: `15,500원`).

## 3. 테스트 케이스 표

| 번호 | 입차 시각 | 출차 시각 | 주차 시간 | 기대 요금 | 비고 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 1 | 09:00 | 09:30 | 30분 | 0원 | 무료 시간 내 |
| 2 | 09:00 | 09:31 | 31분 | 500원 | 10분 단위 올림 적용 |
| 3 | 09:00 | 10:00 | 60분 | 1,500원 | (60-30)/10 * 500 |
| 4 | 00:00 | 23:59 | 23시간 59분 | 20,000원 | 일일 최대 요금 제한 적용 |
| 5 | 10:00 | 09:00 | - | 에러 | 출차 < 입차 (자정 통과 불가) |
| 6 | 25:00 | 26:00 | - | 에러 | 잘못된 시간 형식 |
| 7 | 09:00 | (빈칸) | - | 에러 | 빈 입력 처리 |
